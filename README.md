# قدم‌های فاطمه — PWA

## استفاده سریع
1. همه فایل‌ها را در ریشه Repository گیت‌هاب قرار بده.
2. GitHub Pages / Static HTML را Deploy کن.
3. لینک سایت را روی موبایل فاطمه باز کن.
4. از مرورگر Add to Home Screen / Install App بزن.
5. هر ماموریت با زدن تیک، XP می‌دهد. دوباره تیک را برداری XP همان ماموریت کم می‌شود.
6. «ارسال گزارش امروز» خلاصه امتیاز و استمرار را Share/Copy می‌کند.
7. `partner.html` پنل همراه است.

## مهم: پنل همراه روی دو گوشی
بدون Firebase، داده‌ها فقط روی همان مرورگر/گوشی ذخیره می‌شوند. برای دیدن زنده روی گوشی دیگر:

1. یک پروژه در Firebase بساز.
2. Realtime Database را فعال کن. برای نمونه اولیه می‌توانی Test mode را انتخاب کنی. (برای استفاده طولانی‌مدت حتماً Rules امن بگذار.)
3. در Project Settings یک Web App بساز و config را کپی کن.
4. فایل `firebase-config.js` را باز کن و مقادیر را جای خالی‌ها قرار بده.
5. فایل را Commit کن و صبر کن GitHub Pages دوباره Deploy شود.
6. داخل اپ فاطمه یک کد مشترک مثل `FATEMEH24` ثبت کن.
7. در گوشی خودت لینک `.../partner.html` را باز کن و همان کد را وارد کن.

## تغییر اسم یا جایزه‌ها
- اسم بالای صفحه در `index.html` است.
- جایزه‌ها و امتیازها در آرایه `rewards` داخل `app.js` هستند.
- ماموریت‌های پیش‌فرض در `defaultTasks` داخل `app.js` هستند.

## اگر بعد از آپدیت هنوز نسخه قبلی را دیدی
چون PWA کش دارد، یک بار سایت را با Refresh کامل باز کن یا اپ نصب‌شده را ببند و دوباره باز کن. در صورت نیاز Site data مرورگر را برای همان سایت پاک کن.
