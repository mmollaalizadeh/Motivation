# قدم‌های فاطمه — PWA انگیزشی

نسخه شخصی‌سازی‌شده برای فاطمه با تمرکز روی استمرار، امتیاز و جایزه.

## امکانات
- امتیاز امروز و امتیاز کل
- استریک روزانه
- Level
- ماموریت‌های قابل ویرایش
- جایزه‌های قابل ویرایش
- نمایش «جایزه بعدی»
- نمودار ۷ روز اخیر
- تایمر تمرکز ۳۰ دقیقه‌ای
- دکمه «ارسال گزارش» برای Share/Copy کردن گزارش پیشرفت
- ذخیره اطلاعات روی همان دستگاه با LocalStorage
- قابلیت نصب به عنوان PWA

## نکته مهم درباره گزارش
اطلاعات فعلاً فقط روی دستگاه فاطمه ذخیره می‌شود. برای دیدن گزارش روی دستگاه دیگر، فاطمه باید دکمه «ارسال گزارش» را بزند. برای داشبورد زنده روی دو دستگاه، نسخه بعدی باید به یک دیتابیس مانند Firebase یا Supabase وصل شود.

## GitHub Pages
فایل‌ها را مستقیم در ریشه Repository قرار دهید. اگر Pages روی GitHub Actions است، Workflow نوع Static HTML مناسب است.
