# قدم بعدی — PWA انگیزشی

یک PWA فارسی و راست‌چین برای ایجاد انگیزه با ماموریت روزانه، امتیاز، استریک و جایزه.

## امکانات
- ماموریت‌های روزانه با امتیاز
- استریک روزهای استمرار
- Level و XP
- جایزه‌های قابل باز شدن
- افزودن ماموریت و جایزه شخصی
- پیام انگیزشی قابل شخصی‌سازی
- تایمر تمرکز ۳۰ دقیقه‌ای
- نمودار فعالیت ۷ روزه
- نصب به عنوان PWA
- ذخیره اطلاعات روی همان دستگاه با LocalStorage
- کارکرد آفلاین بعد از اولین بازدید

## انتشار روی GitHub Pages
1. در GitHub یک Repository جدید بساز، مثلاً `ghadam-badi`.
2. تمام فایل‌های داخل این پوشه را در ریشه Repository آپلود کن؛ یعنی `index.html` باید مستقیماً در ریشه باشد.
3. Commit کن.
4. در GitHub برو به: **Settings → Pages**.
5. در قسمت **Build and deployment**، Source را روی **Deploy from a branch** بگذار.
6. Branch را `main` و Folder را `/ (root)` انتخاب کن و Save بزن.
7. بعد از فعال شدن Pages، آدرس سایت چیزی شبیه این می‌شود:
   `https://USERNAME.github.io/ghadam-badi/`

## نصب روی موبایل
- Android / Chrome: سایت را باز کن و گزینه **Install app / Add to Home Screen** را بزن.
- iPhone / Safari: Share → **Add to Home Screen**.

## شخصی‌سازی سریع
بعد از باز شدن اپ، از آیکن ⚙️ اسم و پیام اصلی را تغییر بده. همچنین از داخل اپ می‌توانی ماموریت و جایزه جدید اضافه کنی.

## نکته
داده‌ها فعلاً فقط روی همان مرورگر/گوشی ذخیره می‌شوند و بین دستگاه‌ها Sync نمی‌شوند؛ این باعث می‌شود نسخه بدون سرور و رایگان روی GitHub Pages اجرا شود.
